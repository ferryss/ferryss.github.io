AI项目总结

2025-11-06

项目目标与核心功能

该项目是一个基于Spring AI的智能助手平台，主要目标是构建一个集成多种AI能力和工具的聊天系统。其核心功能包括：

基础聊天功能：支持与AI模型进行对话交互

RAG（检索增强生成）功能：通过Redis向量库存储和检索文档知识，增强AI回答的准确性

互联网搜索功能：集成SearXNG搜索引擎，让AI能够获取实时信息

MCP工具集成：支持多种MCP（Model Context Protocol）工具，如文件系统访问、邮件发送等

系统整体架构

mcp-client（客户端模块）：

  • 提供Web API接口
  • 集成OpenAI等大语言模型
  • 管理Redis向量存储
  • 集成SearXNG搜索引擎
  • 实现SSE（Server-Sent Events）实时通信

mcp-server（服务端模块）：

  • 实现MCP协议服务器
  • 提供邮件发送等工具功能
  • 集成MyBatis-Plus操作数据库
  • 两个模块通过MCP协议进行通信，客户端可以调用服务端提供的各种工具。

关键业务流程

  1. 文档上传与RAG处理流程：
    用户通过uploadRagDoc接口上传文档
    系统使用TextReader读取文档内容
    通过CustomTextSplitter对文档进行分段处理
    使用RedisVectorStore将文档向量化并存储到Redis向量库
  2. RAG问答流程：
    用户发起查询请求到search接口
    系统通过RedisVectorStore进行相似性搜索获取相关文档
    构造包含上下文的提示词发送给AI模型
    AI模型基于上下文生成回答并返回给用户
  3. 互联网搜索流程：
    用户发起互联网搜索请求到/internet/search接口
    系统通过OkHttp调用SearXNG搜索引擎获取结果
    构造包含搜索结果的提示词发送给AI模型
    AI模型综合搜索结果生成回答
  4. MCP工具调用流程：
    AI模型根据用户请求判断是否需要调用工具
    通过MCP协议调用相应的工具（如邮件发送）
    工具执行完成后将结果返回给AI模型
    AI模型综合工具执行结果生成最终回答

使用的技术栈与关键库

后端技术栈：

Spring Boot 3：基础框架
Spring AI：AI集成框架
Redis：向量数据库存储
MyBatis-Plus：数据库访问
MySQL：关系型数据库
OkHttp：HTTP客户端请求
MCP（Model Context Protocol）：工具协议

关键依赖库：

spring-ai-starter-model-openai：OpenAI模型集成
spring-ai-starter-vector-store-redis：Redis向量存储
spring-ai-starter-model-transformers：文本向量化处理
spring-ai-tika-document-reader：文档读取
spring-ai-starter-mcp-client/server：MCP协议支持
okhttp3：网络请求
mybatis-plus-boot-starter：数据库操作
flexmark：Markdown转HTML

特殊设计或技术难点

  1. 自定义文本分割器
    项目实现了CustomTextSplitter类，使用\s*\r\n\s*\r\n\s*正则表达式按段落分割文本，比默认的TokenTextSplitter更适合中文文档处理。
  2. 多种通信方式集成
    项目同时支持：
    SSE（Server-Sent Events）实现实时通信
    MCP协议工具调用
    标准HTTP API接口
  3. 环境变量管理
    使用dotenv-java库管理敏感配置信息，通过.env文件存储API密钥等敏感信息，提高安全性。
  4. 复杂的提示词工程
    项目针对不同场景（RAG问答、互联网搜索、邮件发送等）设计了专门的提示词模板，确保AI能够准确理解上下文并生成合适的回答。
  5. 工具集成与调用
    通过MCP协议集成多种工具，包括文件系统访问和邮件发送功能，使得AI能够在需要时调用这些工具完成复杂任务。
    这个项目充分展示了如何将Spring AI与各种外部服务集成，构建一个功能丰富的智能助手系统。
