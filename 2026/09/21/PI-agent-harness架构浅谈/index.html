PI agent harness架构浅谈

2026-09-21

1. PI将harness层拆成了四个可扩展部分

  • 扩展层：这里的扩展层可以是钩子函数包装成的扩展，也可以是MCP服务，skill，虽然官方不支持MCP等功能，但是我们都可以通过扩展实现，包括通过扩展控制不同的挂载点。
  • skill层：这个就是根据当前持有的skill，渐进式披露工具的信息，通过不同skill，达到不同的效果。
  • 提示词层: PI可以将AGENTS.md， SYSTEM.md, CLUADE.md等加入到上下文提示词中，先加载全局，在加载项目级
  • 主题层: TUI外观

这个分层思路本身就是一种 harness 设计：把”模型能看到什么、什么时候能看到”完全交给规则和扩展，而不是写死在内核里。
